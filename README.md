# RepGrind

CrossFit rep counter that runs in the phone's browser: count reps, For time / AMRAP / EMOM / Chipper / 21-15-9 / intervals,
voice counting (English, Finnish), charts, export to WodConnect, Garmin Connect and Strava, and **WOD Code** – several phones in one workout.

**Open the app:** https://<username>.github.io/repgrind/ – then *Add to Home Screen*. Works offline after the first visit.

Your workouts stay on your phone; nothing is sent to this site. WOD Code connects phones directly (WebRTC via public Nostr relays, using
[Trystero](https://github.com/dmotz/trystero), MIT licence).

Version 2.4.0. This repository holds only the built app; it is published from a private project.
