Tap mode

A tap counts only after the finger is lifted, and only the first finger counts. Taps closer together than this are ignored: raise it if one tap counts twice. Default 350 ms.

Voice counting

Counter and Wi-Fi

Optional: join your gym/home Wi-Fi too. The counter's own hotspot stays on. On that network open http://repgrind.local.

Role at power-on. Automatic: the first counter switched on is the hub, and counters switched on later join it as satellites. The same choice is on the counter: hold its button while switching it on (Auto / HUb / SAt).

Double-hit protection: the shortest time between two reps of one button. Satellites follow it too.

ms

Firmware update

Make the file in the Arduino IDE: Sketch → Export Compiled Binary. Use RepCounterESP32.ino.bin (not the bootloader or partitions file). This updates this counter. A satellite is updated on its own: hold its button while switching it on for about 8 s, until the display shows UPd, join the Wi-Fi RepGrind-Update and open http://192.168.4.1.

What's new

Counts only that the app was opened, a workout was finished or a WOD Code was created. No names, reps or results, no cookies.

Something not working? Open the previous version (2.5.0). It uses the same saved workouts and history.
